# gig-tracker-updates
Signed Firefox builds of Gig Tracker and the `updates.json` that installed
copies check for new versions. Written automatically on each release — do
not edit by hand.

**Install:** download the newest `.xpi` under `releases/`, then in Firefox
open `about:addons`, click the gear icon, and choose **Install Add-on From
File…**. After that it updates itself.
